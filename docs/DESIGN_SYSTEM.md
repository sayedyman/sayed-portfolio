# Design System

## Core Design Philosophy

The interface should feel:
- cinematic
- editorial
- minimal
- premium
- immersive
- calm
- intentional

The design system prioritizes:
- typography
- whitespace
- restrained interactions
- visual hierarchy
- emotional pacing

Avoid:
- generic SaaS styling
- dashboard-heavy layouts
- flashy UI
- loud motion
- crypto aesthetics
- gaming visuals
- crowded compositions

---

# Color System

## Primary Background
Use deep matte dark tones.

Preferred feeling:
- atmospheric
- cinematic
- premium
- textured

Avoid:
- flat black
- bright gray surfaces
- harsh contrast

---

## Accent Color

Primary accent:
- Warm cinematic yellow

Purpose:
- highlight important interactions
- guide attention
- reinforce clarity and intentionality

Use carefully for:
- hover states
- links
- subtle typography highlights
- CTA emphasis

Avoid:
- overusing the accent
- neon/glowing yellow
- aggressive shadows

---

# Typography System

Typography is a major part of the visual identity.

## Typography Style

Use:
- large editorial headings
- calm readable body text
- strong hierarchy
- generous spacing
- controlled line lengths

Typography should feel:
- elegant
- modern
- intelligent
- premium

Avoid:
- dense paragraphs
- tiny text
- excessive font weights
- generic startup typography

---

# Layout System

The layout should prioritize:
- breathing room
- calm pacing
- immersive composition
- editorial rhythm

Use:
- large spacing between sections
- asymmetrical balance when appropriate
- controlled content widths
- intentional alignment

Avoid:
- cramped layouts
- tight grids
- component-heavy structures
- visually noisy sections

---

# Component Direction

## Buttons

Buttons should feel:
- premium
- restrained
- intentional

Preferred interactions:
- subtle shimmer
- soft hover transitions
- gentle movement
- smooth opacity shifts

Avoid:
- oversized glows
- aggressive animations
- gaming-style hover effects

---

## Cards

Avoid traditional heavy card systems.

Instead:
- prioritize content-first composition
- use subtle separators
- use atmospheric depth
- minimize visible borders

Cards should feel:
- editorial
- lightweight
- cinematic

---

# Motion System

All motion should feel:
- smooth
- restrained
- cinematic
- premium

Preferred motion:
- subtle translate-y
- opacity transitions
- ambient reveals
- soft parallax
- smooth Framer Motion transitions

Avoid:
- aggressive scaling
- bouncing animations
- excessive motion
- flashy reveals

Animations should support atmosphere, not distract from content.

---

# Imagery Direction

Images should feel:
- cinematic
- atmospheric
- editorial
- premium

Preferred treatments:
- subtle grain
- dark compositions
- blurred ambient surfaces
- fade edges
- matte textures

Avoid:
- obvious AI images
- corporate stock photos
- oversaturated visuals
- fake dashboard overload

---

# Section Philosophy

Each section should:
- contribute to narrative pacing
- feel immersive
- preserve calm spacing
- avoid repetition

Avoid:
- repeated CTA sections
- stacked conversion blocks
- overly similar layouts

Every section should feel intentional and curated.

---

# Hover Interaction Rules

Hover interactions should be:
- subtle
- elegant
- restrained

Preferred hover behavior:
- soft yellow accent shifts
- slight movement
- ambient opacity changes
- gentle depth

Avoid:
- large hover scaling
- strong glow effects
- flashy animations

---

# Responsive Philosophy

Mobile layouts should preserve:
- editorial spacing
- hierarchy
- cinematic pacing

Avoid:
- collapsing everything too tightly
- oversized mobile typography
- crowded mobile sections

The experience should remain premium on all screen sizes.
