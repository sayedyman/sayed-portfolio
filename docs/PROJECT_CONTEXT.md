# Portfolio Project Context

## Project Overview

This project is a premium cinematic portfolio website for Sayed Elghanam, a UI/UX Designer transitioning toward Product Design.

The portfolio is not intended to feel like:

* a generic freelancer website
* an agency landing page
* a dashboard template
* a crowded portfolio gallery

The entire experience should feel:

* cinematic
* editorial
* premium
* minimal
* intentional
* product-focused
* emotionally calm
* luxury-tech inspired

The portfolio emphasizes:

* strong typography
* whitespace
* immersive pacing
* restrained motion
* subtle interaction design
* storytelling
* strategic UX thinking

---

The portfolio should communicate:

# Typography Direction

Typography is a major part of the experience.

The site should feel typography-first.

Use:

* large editorial headings
* calm readable body text
* cinematic hierarchy
* generous spacing
* controlled line lengths

Avoid:

* overly dense text blocks
* tiny typography
* excessive font mixing
* corporate SaaS typography feeling

Typography should feel:

* premium
* intentional
* modern
* elegant

---

# Motion & Interaction Philosophy

Motion should always feel:

* subtle
* intentional
* premium
* smooth
* cinematic

Preferred interactions:

* soft opacity shifts
* slight translate motion
* ambient hover reveals
* restrained Framer Motion transitions
* smooth scroll pacing
* subtle shimmer effects

Avoid:

* strong scale animations
* aggressive glowing overlays
* loud hover effects
* over-animated UI
* excessive motion

Animations should enhance atmosphere, not demand attention.
